# Руководство: Персонажи как модули

## Концепция

Каждый персонаж — независимый модуль с:
- Системным промптом
- Собственным набором **режимов работы** (CharacterMode)
- Флагом `nsfw_capable` — может ли персонаж использоваться в NSFW режимах

Режимы привязаны к персонажу, а не глобальны. Пользователь выбирает режим **внутри конкретной сессии**.

---

## Создание персонажа (через БД / Drizzle Studio)

Открыть Drizzle Studio: `npm run db:studio`

### Таблица `characters`

| Поле | Тип | Описание |
|------|-----|----------|
| `slug` | varchar(100) | Уникальный идентификатор (напр. `morgan`) |
| `name` | varchar(255) | Отображаемое имя (напр. `Морган`) |
| `description` | text | Короткое описание для меню персонажей |
| `system_prompt` | text | Системный промпт — основа личности персонажа |
| `avatar_url` | varchar | URL аватара (опционально) |
| `is_active` | bool | Виден ли персонаж пользователям |
| `nsfw_capable` | bool | Может ли персонаж использоваться в NSFW режимах |

**Пример INSERT:**
```sql
INSERT INTO characters (slug, name, description, system_prompt, is_active, nsfw_capable)
VALUES (
  'aria',
  'Ария',
  'Загадочная AI-ассистент с острым умом',
  'Ты — Ария, интеллектуальный AI-компаньон...',
  true,
  false
);
```

## Создание режимов персонажа

### Таблица `character_modes`

| Поле | Тип | Описание |
|------|-----|----------|
| `char_id` | int | FK на персонажа |
| `slug` | varchar(100) | Идентификатор режима (напр. `default`, `flirty`) |
| `name` | varchar(255) | Название для отображения пользователю |
| `prompt_addon` | text | Дополнение к системному промпту в этом режиме |
| `is_nsfw` | bool | Требует ли режим NSFW доступ |
| `is_default` | bool | Режим по умолчанию для нового чата |
| `sort_order` | int | Порядок сортировки в меню |

**Пример: создать режим «Дружелюбный» и «Романтичный»:**
```sql
-- Обычный режим (по умолчанию)
INSERT INTO character_modes (char_id, slug, name, prompt_addon, is_nsfw, is_default, sort_order)
VALUES (1, 'friendly', 'Дружелюбный', NULL, false, true, 0);

-- Флиртующий режим (только Premium/KYC)
INSERT INTO character_modes (char_id, slug, name, prompt_addon, is_nsfw, is_default, sort_order)
VALUES (1, 'flirty', 'Романтичный', 'В этом режиме ты ведёшь себя флиртующе и романтично, но остаёшься в рамках PG-13.', false, false, 1);

-- NSFW режим (только Premium + KYC, не Корея)
INSERT INTO character_modes (char_id, slug, name, prompt_addon, is_nsfw, is_default, sort_order)
VALUES (1, 'nsfw', '🔞 Взрослый', 'В этом режиме разрешён откровенный 18+ контент...', true, false, 2);
```

> **Важно:** NSFW режимы (`is_nsfw = true`) требуют от персонажа `nsfw_capable = true`. Обновите поле `nsfw_capable` у персонажа если добавляете NSFW режим.

## Как пользователь выбирает режим

1. Пользователь нажимает **«💬 Сессии»** в главном меню
2. Выбирает персонажа
3. В списке сессий рядом с каждой сессией есть кнопка **«⚙️»**
4. Открывается список режимов — доступные и заблокированные 🔒
5. Режим применяется только к данной сессии

Смена режима не влияет на другие сессии того же персонажа.

---

## Как работает prompt_addon

При обработке сообщения `ChatService` строит системный промпт так:

```
[character.system_prompt]

[mode.prompt_addon]   ← добавляется если режим выбран

[SAFETY addon]        ← добавляется если пользователь без NSFW доступа
```

`prompt_addon` может быть любым текстом — инструкцией, ограничением, изменением личности.

## Тестирование нового персонажа

1. Добавить персонажа в БД через Drizzle Studio
2. Запустить бот локально: `npm run dev`
3. Нажать «🎭 Персонажи» → выбрать нового персонажа
4. Протестировать диалог
5. Добавить режимы если нужно
