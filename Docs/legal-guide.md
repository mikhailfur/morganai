# Гайд: Модульная система /legal документов

Все правовые документы хранятся как TypeScript-модули в `client/src/legal/`.
Страница `/legal` автоматически строит меню и отображает контент из этих файлов.

---

## Структура папки

```
client/src/legal/
├── types.ts        ← типы LegalDoc и LegalSection (не трогать)
├── index.ts        ← реестр всех документов (добавляй сюда)
├── privacy.ts      ← Политика конфиденциальности
├── terms.ts        ← Условия использования
├── oferta.ts       ← Публичная оферта
├── refund.ts       ← Политика возврата средств
└── cookie.ts       ← Cookie-политика
```

---

## Как редактировать существующий документ

1. Открой нужный файл, например `client/src/legal/privacy.ts`
2. Измени нужные поля:
   - `name` — название в меню слева
   - `version` — версия/дата (отображается под заголовком)
   - `heading` — крупный заголовок страницы (перенос строки: `\n`)
   - `summary` — краткое описание (отображается в блоке «Кратко» справа)
   - `sections` — массив параграфов

3. Сохрани файл. Изменения применяются без перезапуска (hot reload в dev).

### Структура параграфа

```ts
{
  sym: '§ 1',       // символ/номер параграфа
  title: 'Название', // заголовок
  text: 'Текст...',  // основной текст параграфа
}
```

## Как добавить новый документ

### Шаг 1 — Создай файл

Скопируй любой существующий файл, например `privacy.ts`, назови по slug:

```
client/src/legal/my-new-doc.ts
```

Заполни все поля. `id` должен быть уникальным — он используется в URL (`/legal/my-new-doc`).

```ts
import type { LegalDoc } from './types'

const myNewDoc: LegalDoc = {
  id: 'my-new-doc',        // slug для URL: /legal/my-new-doc
  num: '06',               // номер в меню (для отображения)
  name: 'Мой документ',   // название в меню
  version: 'v1.0 · май 2026',
  heading: 'Мой\nдокумент.',
  summary: 'Краткое описание в одно предложение.',
  sections: [
    {
      sym: '§ 1',
      title: 'Раздел 1',
      text: 'Текст первого раздела.',
    },
  ],
}

export default myNewDoc
```

### Шаг 2 — Зарегистрируй в реестре

Открой `client/src/legal/index.ts` и добавь импорт и элемент в массив:

```ts
import myNewDoc from './my-new-doc'   // ← добавить импорт

export const legalDocs: LegalDoc[] = [
  privacy,
  terms,
  oferta,
  refund,
  cookie,
  myNewDoc,  // ← добавить в конец
]
```

Документ сразу появится в меню на странице `/legal` и будет доступен по URL `/legal/my-new-doc`.

---

## Как удалить документ

1. Удали импорт и элемент массива из `client/src/legal/index.ts`
2. При желании удали сам файл

---

## Соглашения

- `id` — kebab-case, совпадает с именем файла и URL-параметром
- `num` — двузначный номер с ведущим нулём: `'01'`, `'06'` и т.д.
- Для переноса строки в `heading` используй `\n`
- `version` — свободный текст, рекомендуемый формат: `v1.0 · месяц год`
