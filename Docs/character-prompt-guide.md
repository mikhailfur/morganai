# Гайд: Персонажи и промпты в Morgan AI

## Добавление нового персонажа

### 1. Создай файл персонажа

Создай `server/src/characters/имя_персонажа.ts`:

```typescript
import type { CharacterDefinition } from './types';

const alisa: CharacterDefinition = {
  slug: 'alisa',              // URL-safe уникальный ID (только a-z, 0-9, дефис)
  name: 'Алиса',             // Отображаемое имя
  description: 'Краткое описание для пользователей',
  systemPrompt: `Ты — Алиса, ...

## Контекст пользователя
Имя пользователя: {{user_name}}
Текущее время: {{user_time}}
Дата: {{current_date}}

// ... остальной промпт ...
  `,
  greetingMessage: 'Первое сообщение при открытии чата',
  isPremium: false,   // true = только для Premium/Premium+
  isActive: true,     // false = скрыт от пользователей
  sortOrder: 2,       // Порядок в списке (меньше = выше)
};

export default alisa;
```

### 2. Добавь в index.ts

В `server/src/characters/index.ts`:

```typescript
import alisa from './alisa';

export const characters: CharacterDefinition[] = [
  morgan,
  alisa,   // ← добавь сюда
];
```

### 3. Пересобери и запусти

```bash
npm run dev
```

Персонаж автоматически добавится в БД при старте сервера (если слот с таким slug пустой).

## Доступные переменные промпта

Используй `{{variable}}` в поле `systemPrompt`:

| Переменная | Описание | Пример |
|-----------|----------|--------|
| `{{user_name}}` | Имя пользователя | `Михаил` |
| `{{user_time}}` | Локальное время пользователя | `14:32` |
| `{{current_date}}` | Текущая дата | `15 мая 2026` |

Клиент автоматически передаёт `clientTimezone` в каждом запросе — сервер конвертирует UTC во время пользователя.

## Формат ответа персонажа

```
*действие/эмоция курсивом*     ← описание действий в звёздочках
Речь обычным текстом            ← что говорит персонаж вслух
(мысль в скобках)               ← внутренние мысли
[VOICE: текст для озвучки]      ← генерируется MiniMax TTS
```

### Голосовые паузы (только внутри VOICE)
```
[VOICE: Привет. <#1.5#> Как дела?]
```
`<#1.5#>` — пауза 1.5 секунды. Используй только внутри `[VOICE: ...]`.

## Режимы поведения (modes)

Режим применяется к любому персонажу как дополнение к system prompt.

Добавить новый режим — **4 места**:
1. `server/src/prompt.ts` → добавить case в `getBehaviorPrompt()`
2. `client/src/views/ChatView.vue` → массив `modes`
3. `client/src/views/SettingsView.vue` → массив `modes`
4. `server/src/routes/user.routes.ts` → массив `validModes`

## Пример полного system prompt

```
Ты — Алиса, игривая и умная AI-компаньон.

## Контекст пользователя
Имя: {{user_name}}
Время: {{user_time}}
Дата: {{current_date}}

## Характер
* Любопытная, с лёгкой иронией
* Любит задавать вопросы в ответ

## Механика ответов
* Речь — основной текст
* *действие* — в звёздочках
* (мысль) — в скобках

## Голосовые [VOICE]
Частота: 10-15%. Длина: 2-3 предложения.
```
