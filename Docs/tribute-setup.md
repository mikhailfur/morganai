# Настройка подписки через Tribute

## Принцип работы

Tribute создаёт приватный Telegram-канал. Пользователь, оформивший подписку, автоматически добавляется в этот канал. Бот проверяет членство через Telegram API (`getChatMember`) — если пользователь в канале, Premium активируется. Если уходит из канала — Premium отзывается автоматически.

Никакого Tribute API не используется. Только проверка членства в канале.

## Пошаговая настройка

### Шаг 1. Создать приватный Telegram-канал через Tribute

1. Зайди на [tribute.tg](https://tribute.tg) и создай подписку
2. Tribute создаст приватный Telegram-канал и свяжет его с твоей подпиской
3. Получи ссылки на покупку для разных сроков (1 месяц, 3, 6, 12) — они будут в виде `t.me/...` или ссылок Tribute

### Шаг 2. Добавить бота в канал как администратора

Это критически важно: без прав администратора `getChatMember` не работает для не-членов канала.

1. Открой канал в Telegram
2. Настройки → Администраторы → Добавить администратора
3. Найди бота `@morganai_bot` (или как называется бот)
4. Дай права: минимум **нет специальных прав** (достаточно добавить в список)

### Шаг 3. Получить ID канала

Самый простой способ:
1. Перешли любое сообщение из приватного канала боту `@userinfobot`
2. Бот вернёт ID в виде `-100XXXXXXXXXX`

Альтернативно: добавь `@getidsbot` в канал — он сразу покажет ID.

### Шаг 4. Прописать переменные окружения

В Dokploy → Environment Variables добавь:

```
TRIBUTE_CHANNEL_ID=-100XXXXXXXXXX
TRIBUTE_LINK_1M=https://t.me/tribute/...
TRIBUTE_LINK_3M=https://t.me/tribute/...
TRIBUTE_LINK_6M=https://t.me/tribute/...
TRIBUTE_LINK_12M=https://t.me/tribute/...
```

> Можно добавить только часть ссылок — кнопки появляются только для тех сроков, где ссылка задана. Например, только `TRIBUTE_LINK_1M` и `TRIBUTE_LINK_3M`.

### Шаг 5. Редеплой

После добавления переменных — задеплой приложение в Dokploy. Бот подхватит новые env-переменные.

## Как работает для пользователя

1. Пользователь нажимает «💎 Получить Premium» в главном меню
2. Видит экран с кнопками выбора срока подписки и кнопкой «✅ Я подписался — проверить»
3. Переходит по нужной ссылке → оформляет подписку в Tribute → автоматически добавляется в приватный канал
4. Возвращается в бот → нажимает «✅ Я подписался — проверить»
5. Бот проверяет членство в канале:
   - Есть в канале → Premium активируется, `premiumSource = 'tribute'` записывается в БД
   - Нет в канале → сообщение «Подписка не найдена»

## Автоматическая проверка и отзыв

При каждом `/start` бот в фоне (fire-and-forget) перепроверяет статус Tribute-подписчиков. Интервал — не чаще раза в час (кеш `tributeCheckedAt` в БД).

Если пользователь ушёл из канала (отменил подписку):
- `tributeVerified` → `false`
- Если `premiumSource = 'tribute'` → tier понижается до `'free'`
- Если `premiumSource = 'manual'` (выдан администратором) → tier не меняется

## Флаги в базе данных

| Поле                 | Описание                                                    |
|----------------------|-------------------------------------------------------------|
| `tribute_verified`   | `true` если пользователь сейчас в Tribute-канале            |
| `tribute_checked_at` | Время последней проверки (для троттлинга раз в час)         |
| `premium_source`     | `'tribute'` или `'manual'` или `null`                       |

## Если Tribute не настроен

Если `TRIBUTE_CHANNEL_ID` не задан:
- Кнопки подписки на Premium-экране не показываются
- Отображается старое сообщение: «Для получения Premium обратитесь к администратору»
- Бот работает в штатном режиме без Tribute
