# Система изображений в меню бота

## Как это работает

Бот ищет картинки в папке `image/` в корне проекта. Если файл найден — меню отображается как фото с caption и кнопками. Если файла нет — меню показывается как обычный текст (без ошибок).

После первой отправки Telegram возвращает `file_id` — уникальный идентификатор файла. Он кешируется в памяти бота. При следующих показах того же экрана файл повторно не загружается: используется кешированный `file_id`. Это делает навигацию мгновенной.

## Структура папки

```
image/
├── banner.jpg          ← /start, главное меню, экран «Назад»
├── premium.jpg         ← экран Premium / Tribute подписки
├── sfw.jpg             ← вкладка SFW в выборе персонажей
├── nsfw.jpg            ← вкладка NSFW в выборе персонажей
└── characters/
    ├── default.jpg     ← заглушка для персонажей без своей картинки
    ├── morgan.jpg      ← картинка персонажа Morgan (slug = "morgan")
    └── aria.jpg        ← картинка персонажа Aria (slug = "aria")
```

### Соответствие экранов и файлов

| Экран бота                      | Файл                                |
|---------------------------------|-------------------------------------|
| `/start`, главное меню          | `image/banner.*`                    |
| Меню Premium / Tribute          | `image/premium.*`                   |
| Список персонажей (SFW вкладка) | `image/sfw.*`                       |
| Список персонажей (NSFW вкладка)| `image/nsfw.*`                      |
| Карточка персонажа              | `image/characters/{slug}.*`         |
| Персонаж без своей картинки     | `image/characters/default.*`        |

Имя файла персонажа = поле `slug` в таблице `characters`. Например, персонаж с `slug = "morgan"` → файл `image/characters/morgan.jpg`.

## Поддерживаемые форматы

`.jpg`, `.jpeg`, `.png`, `.webp` — проверяются именно в таком порядке.

## Как добавить / обновить картинки

1. Положи файлы в папку `image/` (локально)
2. Закоммить и запушить:
   ```bash
   git add image/
   git commit -m "chore: update bot images"
   git push origin dev
   ```
3. CI пересоберёт Docker-образ с новыми картинками → Dokploy задеплоит автоматически

> **Примечание:** `file_id` кешируется только в памяти бота (in-memory). При перезапуске бота кеш сбрасывается, и при первом показе каждого экрана файл снова загружается с диска (один раз). Это нормальное поведение.

## Если картинки не нужны

Просто не добавляй файлы — бот продолжит работать в текстовом режиме. Файлы `.gitkeep` в репозитории нужны только для того, чтобы папки попали в git.

## Технические детали

- Реализация: `src/bot/helpers/image-cache.ts` (загрузка, кеш) и `src/bot/helpers/screen.ts` (показ экрана)
- `screen.ts` автоматически определяет тип текущего сообщения (фото или текст) и вызывает нужный Telegraf-метод:
  - Фото → фото: `editMessageMedia` (меняет картинку)
  - Текст → текст: `editMessageText`
  - Фото → текст: `editMessageCaption` (картинка остаётся, меняется текст)
  - Текст → фото: `replyWithPhoto` (новое сообщение)
